# Aixgo documentation, full text

> Aixgo is a production-grade AI agent framework for Go. It enables secure, scalable multi-agent systems with no Python dependencies, single-binary deployment under 20MB, sub-100ms cold starts, and true parallel concurrency (no GIL).

Every guide published at {{ $site }}/guides/, markdown source inlined, in the order the guides index lists them. Generated when the site builds. The curated link index, which also covers the products, the blog and the current release, is at {{ $site }}/llms.txt.

The product pages and the homepage are not inlined here. Their prose lives in Hugo templates and data files rather than in markdown, so there is no source to include. Read them at {{ $site }}/code/, {{ $site }}/aixgate/ and {{ $site }}/.

Each guide below starts with a level-one heading, its source URL and its category.
