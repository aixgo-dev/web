{{- /*
  /llms.txt, in the format proposed at https://llmstxt.org/: one H1, a
  blockquote summary, prose, then H2 sections of `- [title](url): description`
  links.

  This file used to be static/llms.txt, written by hand. It went stale the way
  hand-maintained artifacts do: it never mentioned Aixgo Code or Aixgate, it
  never picked up the goals-gates-loops guide, it listed no blog posts, and
  nothing anywhere went red about any of it. The header block below is still
  that hand-written copy, kept because it is good and because it describes the
  framework's shape rather than its inventory. Everything under the first H2 is
  read out of content/ and data/, so a new guide, product or post lands here on
  the next build, and no count in a generated line can drift.

  scripts/check-llms.sh grades the built file. Rename a section heading here and
  you rename it there too.
*/ -}}
{{- /*
  One list entry. This is a define rather than a partial on purpose: Hugo parses
  partials as html/template even when the calling template is plain text, which
  ships the category "RAG & Embeddings" as "RAG &amp; Embeddings" and every
  apostrophe as "&#39;". A define is parsed in this template's own text
  namespace and stays literal. check-llms.sh fails on an escaped entity, so a
  future move back to a partial goes red rather than quietly mangling the file.

  Descriptions come from front matter and data/*.yaml, where a folded block can
  carry newlines. Collapsing whitespace keeps each entry on one line.
*/ -}}

{{- $desc := .desc | replaceRE `\s+` " " | chomp -}}
- [{{ .title }}]({{ .url }}){{ with $desc }}: {{ . }}{{ end }}
{{ end -}}

# Aixgo

> Aixgo is a production-grade AI agent framework for Go. It enables secure, scalable multi-agent systems with no Python dependencies, single-binary deployment under 20MB, sub-100ms cold starts, and true parallel concurrency (no GIL).

Aixgo targets backend Go engineers, DevOps teams, and data engineers who need to ship AI agents in production without the operational overhead of Python frameworks like LangChain or LlamaIndex. The framework provides 13 orchestration patterns (Supervisor, Sequential, Parallel, Router, Swarm, Hierarchical, RAG, Reflection, Ensemble, Classifier, Aggregation, Planning, MapReduce), 6 agent types (ReAct, Classifier, Aggregator, Planner, Producer, Logger), 8+ LLM providers (OpenAI, Anthropic, Gemini, xAI, Vertex AI, Amazon Bedrock, HuggingFace, plus inference services), Pydantic AI-style validation retry for structured output, and Model Context Protocol (MCP) tool calling.

Every link below is read out of this site's own pages and data files when the site builds, and a CI gate fails the build when the result stops matching what was published. The full text of every guide is at {{ $site }}/llms-full.txt.
